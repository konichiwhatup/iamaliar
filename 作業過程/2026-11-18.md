# 作業記録 2026-11-18

## 1. 画像表示の修正（object-cover → object-contain）

### 問題
アップロードした写真がプレビューで全体表示されず、寄った状態で表示されていた。
原因：全箇所で `object-cover` + `aspect-[3/4]` を使用しており、写真が3:4でない場合にトリミングされていた。

### 修正内容
全ての画像表示を `object-contain` に変更し、写真全体が表示されるようにした。

| ファイル | 変更内容 |
|---|---|
| `src/app/(site)/gallery/GalleryClient.tsx` | object-cover → object-contain |
| `src/app/(site)/gallery/[slug]/ProductDetailClient.tsx` | object-cover → object-contain（関連商品） |
| `src/components/product/product-gallery.tsx` | object-cover → object-contain（メイン・サムネイル） |
| `src/components/product/product-card.tsx` | object-cover → object-contain |
| `src/app/(site)/news/NewsListClient.tsx` | object-cover → object-contain、4/3アスペクト比 |
| `src/app/(site)/news/[slug]/NewsDetailClient.tsx` | object-cover → object-contain、4/3アスペクト比 |

**補足：** ギャラリーは縦長（3:4）、ニュースは横長（4:3）のコンテナに統一。写真が比率と異なる場合は余白が黒背景で埋まる。
